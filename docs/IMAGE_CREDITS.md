# Real marketplace photograph credits

The demo catalogue uses **real representative photographs**, not generated package artwork. The Home Pharma medicine names remain fictional demo records, so a source photograph may show a different real-world brand or package. The photographs are used only to demonstrate the marketplace interface; no manufacturer endorsement or product identity is implied.

Each photograph was resized, cropped or placed on a neutral canvas for consistent catalogue presentation. Files derived from ShareAlike sources remain subject to the corresponding ShareAlike license.
